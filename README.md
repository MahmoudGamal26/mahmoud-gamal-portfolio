## 🌐 Quick Local Setup & Preview

Since the project uses zero heavy build steps, you can open and run it instantly:

1. Double click `index.html` to view directly in your web browser.
2. Or use any local static server like VS Code Live Server or python:
   ```bash
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000`.

## 🚀 Deployment Instructions

### Option 1: GitHub Pages
1. Push this folder to a GitHub repository named `mahmoud-gamal-portfolio`.
2. Go to **Settings > Pages**.
3. Select `main` branch and root `/` folder, then click **Save**.

### Option 2: Vercel / Netlify
1. Drag and drop the `mahmoud-gamal-portfolio` folder directly into Vercel or Netlify dashboard.
2. It will deploy automatically within seconds!
